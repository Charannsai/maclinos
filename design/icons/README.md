# MaclinOS Icons
# Place original SVG icons here, organized by category.
# Do NOT include any Apple-derived artwork.
#
# Suggested structure:
#   apps/       - Application icons (48x48, 64x64, 128x128 SVG)
#   actions/    - Action icons (toolbar, menu)
#   places/     - Folder, drive, network icons
#   mimetypes/  - File type icons
#   status/     - Status and notification icons
#   devices/    - Hardware device icons
#
# Icon format: SVG with PNG exports at 16, 22, 24, 32, 48, 64, 128, 256px
# Follow freedesktop.org icon naming specification:
# https://specifications.freedesktop.org/icon-naming-spec/latest/
