# MaclinOS Custom Widgets (Plasmoids)
#
# Place custom QML-based Plasma widgets here.
# Each widget should be a separate directory with:
#   metadata.desktop  - Widget metadata
#   contents/
#     ui/
#       main.qml      - Main widget QML
#     config/
#       main.xml      - Configuration schema (if needed)
#
# Potential custom widgets:
#   - Enhanced app launcher (if KRunner is insufficient)
#   - Quick settings panel
#   - Custom notification center
#   - macOS-style Spotlight search
#
# Guidelines:
#   - Only create custom widgets when native Plasma widgets are insufficient
#   - Use KDE Frameworks APIs, not system calls
#   - Test with plasmoidviewer before deploying
#   - Follow KDE coding standards for QML
