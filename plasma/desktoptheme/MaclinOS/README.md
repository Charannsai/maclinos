# MaclinOS Plasma Desktop Theme
#
# This directory will contain the Plasma desktop theme SVG files.
# These control the appearance of panels, tooltips, dialogs, and
# other Plasma shell elements.
#
# Key files needed:
#   metadata.desktop       - Theme metadata
#   dialogs/               - Dialog backgrounds
#   widgets/               - Widget appearance (panel, button, etc.)
#   opaque/                - Non-transparent versions
#   translucent/           - Translucent versions
#
# See: https://develop.kde.org/docs/plasma/theme/theme-details/
